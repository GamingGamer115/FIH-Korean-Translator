# FIH-Korean-Translator

| Keybind | Feature |
| :--- | :--- |
| Ctrl + K | Toggle translator on and off in game, and turning it off puts it back to English. |

Translation uses Google Translate over the internet
Translations can be incorrect. Fix any line by adding it to custom_translations.txt
Text inside images (logos, painted signs) can’t be translated.

Player name tags and text you type are never translated
